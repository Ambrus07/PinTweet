# PinTweet 

Twitter és Pinterest hibrid közösségi platform 

## Telepítés és indítás

1. Telepítsd a függőségeket:
   ```bash
   npm install
   ```

2. Indítsd el a fejlesztői szervert:
   ```bash
   npm start
   ```

3. Nyisd meg: [http://localhost:3000](http://localhost:3000)

## Technológiák
- React 18
- Tabler Icons
- Google Fonts (Playfair Display + Lora)

## Struktúra
```
src/
  App.jsx    — főkomponens (Sidebar, Feed, Pinterest panel)
  App.css    — összes stílus
  index.js   — belépési pont
public/
  index.html — HTML sablon
```
